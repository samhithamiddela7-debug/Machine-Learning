# Height-Weight Prediction using Simple Linear Regression

## Project Overview

This project demonstrates the implementation of Simple Linear Regression using Python and Machine Learning libraries.

The objective is to understand the relationship between weight and height and build a regression model that predicts height based on weight.

This project is part of my practical journey of learning Machine Learning.

## Objectives

- Understand Simple Linear Regression.
- Explore and visualize a dataset.
- Analyze the correlation between variables.
- Perform train-test splitting.
- Apply feature standardization.
- Train a Linear Regression model.
- Make predictions using test data.
- Evaluate model performance using regression metrics.

## Dataset

The project uses a Height-Weight dataset containing two features:

- **Weight:** Independent feature (X).
- **Height:** Dependent feature (y).

## Technologies and Libraries Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Workflow

1. Importing required libraries.
2. Loading the dataset using Pandas.
3. Exploring the dataset.
4. Visualizing data using scatter plots.
5. Analyzing correlation.
6. Separating independent and dependent features.
7. Splitting data into training and testing sets.
8. Standardizing the input feature using StandardScaler.
9. Training the Simple Linear Regression model.
10. Predicting results on test data.
11. Evaluating model performance.

## Model Evaluation Metrics

The model performance is evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R-squared (R²)
- Adjusted R-squared
